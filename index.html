PORTFOLIO / ABOUT

关于这份作品集

围绕实时渲染、GPU 模拟、Shader 和编辑器工具，记录从效果设计到工程实现的探索。这里收录已公开的项目，介绍实现思路，并提供演示与源码入口。

项目方向

  • 渲染与引擎：Vulkan 路径追踪、ReSTIR、时域重建、云雾体积渲染和 Substrate 风格化着色。
  • 模拟与表现：GPU Agent、XPBD 单片布料、视觉破碎与积雪数学。
  • 工具与工作流：Profile 配置、资产烘焙、编辑器预览、科学点云可视化、诊断与捕获。

阅读项目

项目页包含功能、方案、代码入口、运行条件和验证状态。视频展示完整作品；公开代码的组成与集成方式可在各项目 README 中查看。算法参考、第三方依赖和许可保留在对应仓库。
